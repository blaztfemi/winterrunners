# WINTER RUNNERS

A scrollytelling documentary: a true childhood memory from rural Kentucky,
slowly swallowed — one credible document at a time — by an older American
folk mystery.

**This branch is the Fable dream pass**: the creative framework and a
working tone prototype. It is deliberately incomplete; every gap is a
labeled production slot.

## What's here

| File | What it is |
|---|---|
| `index.html` | Working scrollytelling prototype — the tone proof. Zero dependencies, zero build step; open it in a browser or deploy as-is. Implements movements 1–3 fully (including the pinned WOKE / WATCHED / RAN reconstruction), sample sequences from movements 4–6, the ending, presenter keyboard mode, reduced-motion fallbacks, and the one uncanny touch. |
| `DREAM.md` | The creative framework: visual system, the triad, the three-texture weave, named transitions, movement-by-movement direction, conduct rules, and the Opus handoff plan. |
| `MANIFEST.md` | Every placeholder slot mapped to its WR asset ID, real source, rights posture, and verified-language ledger. |

## The pipeline

1. **Fable (done)** — dreamed the framework and proved the tone.
2. **Opus (next)** — fills family-photo and archive slots as Eric drops
   scans into chat, completes movements 4–6 prose from the Research
   Dossier, hardens responsive/reduced-motion/presenter behavior.
3. **Ship** — GitHub → Vercel. Static site; `index.html` at root deploys
   with no configuration.

## House rules (short version)

- Grit lives in the paper, never the letterforms.
- The ember color belongs to the light and almost nothing else.
- Nothing is invented: no fabricated headlines, quotes, channels, or
  family memories. Slots are slots.
- Almost nothing moves. That's why the one thing that runs is terrifying.
